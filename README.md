# 心络 MVP

心络是一个隐私优先的个人记忆整理工具。用户把真实经历写成“心锚”，在纵向时间轴中回看，再用人物、时间、因果三类“心线”把经历连接起来。

当前版本是本地优先、无需注册的移动端 Web/PWA，数据默认只保存在当前浏览器。

在线体验：[https://day7post.github.io/xinlu/](https://day7post.github.io/xinlu/)

## 已实现

- 一句话、照片、场景三类心锚
- 自动保存与单次记录会话历史版本
- 纵向时间轴、最新/最早排序、未定时间区域
- 手动摘要与原文回退摘要
- 具体日期、月份、年份、年段和未知时间
- 用户标签、当时/现在多情绪、可选强度和说明
- 人物、时间、因果三类无向心线
- 时间轴弧线与节点高亮
- 全文与标签搜索
- 心锚、心线 30 天回收站
- 口令加密的完整备份与恢复
- 离线应用与本地持久存储申请

首版有意不包含分享、心程、封锚、AI、人物关系图和神经网。这些能力在本地数据模型上保留后续扩展位置。

## 本地运行

```bash
npm install
npm run dev
```

## 校验

```bash
npm run lint
npm test
npm run build
```

生产构建会生成 PWA Service Worker，可通过 `npm run preview` 本地预览。

推送到 `main` 分支后，GitHub Actions 会自动检查并发布到 GitHub Pages。

## 隐私说明

MVP 的本地数据库不做心锚级加密，拿到已解锁设备与浏览器资料的人可能读取内容。用户主动下载的备份使用 PBKDF2 派生密钥与 AES-GCM 加密。清除浏览器数据会删除本地资料，因此应定期下载备份。
